# Design System

## 1. 目的

本書は、Virtual Vessel Studioの全画面が共通して使用する見た目の定義（Design Tokens）を定める（方式設計14.4、14.34）。

各画面・各Componentは、本書で定義した値のみを使用する。画面ごとに独自の色、文字サイズ、余白を定義しない。

見た目の基準は、次の見本ページで確認できる。

```text
docs/assets/ui/styleboard.html
```

ブラウザで直接開くと、パレット、ダーク／ライト、日本語／英語、色の見え方を切り替えて確認できる。本書と見本ページは常に一致させる。どちらかを変更した場合は、もう一方も同じ変更で更新する。

関連文書：

- `components.md`：共通Componentの仕様
- `ui-guidelines.md`：画面を作るときのルール

---

## 2. デザインの方向性

- VTuber向けのApplicationとして、やわらかく、かわいい印象を持たせる。
- かわいさは、**丸みのある形**と**淡いアクセント色**で表現する。文字の大きさや余白は落ち着かせ、配信中でも読みやすく保つ。
- 既定は紫からピンクの配色（Lavender）とし、利用者が複数のパレットから選択できる。
- 背景は暗い色を基本（ダーク）とし、明るい背景（ライト）にも切り替えられる。
- 色の見え方や身体的な条件に関わらず使えることを、かわいさより優先する（9章）。

## 3. 色

### 3.1 構成

色は次の3種類で構成する。

| 種類 | 内容 | パレットによる変化 |
|---|---|---|
| アクセント | Primary、Secondary | パレットごとに変わる |
| ニュートラル | 背景、面、枠線、文字 | パレットの色相（Hue）をわずかに混ぜる |
| 状態 | 成功、注意、エラー、配信中 | パレットに関わらず固定 |

状態の色をパレットに連動させない理由は、どのパレットでも「緑系は成功、赤系はエラー」という意味を保つためである。

### 3.2 パレット

| パレット | 色相（H） | Primary | Secondary |
|---|---|---|---|
| Lavender（既定） | 268 | `#c3a6ff` | `#ff9ccf` |
| Sakura | 335 | `#ffa3c4` | `#c9a8ff` |
| Mint | 165 | `#7fe0c1` | `#a9d8ff` |
| Sky | 212 | `#8cc4ff` | `#c7b2ff` |
| Peach | 18 | `#ffb08f` | `#ffd88a` |
| Lemon | 48 | `#ffe07a` | `#ffb3cf` |

- Primary、Secondaryはダークとライトで同じ値を使う。どちらも淡い色であり、その上に置く文字は常に`On Accent`（濃い色）とする。
- パレットを追加する場合は、Primaryの上で`On Accent`が4.5:1以上になることを確認する。

### 3.3 ニュートラル

ニュートラルは、パレットの色相Hを使ってHSLで定義する。パレットを切り替えると、背景や面にもわずかに色味が付く。

| Token | 用途 | ダーク（S / L） | ライト（S / L） |
|---|---|---|---|
| Background | 画面全体の背景 | 26% / 8% | 60% / 97% |
| Surface | 画面・パネル | 22% / 12% | 40% / 99% |
| Surface 2 | カード、入力の背景 | 20% / 16% | 45% / 95% |
| Surface 3 | 押せる面、トラック | 18% / 21% | 40% / 91% |
| Border | 枠線、区切り線 | 18% / 26% | 30% / 86% |
| Text | 本文 | 40% / 95% | 30% / 16% |
| Text 2 | 補足、ラベル | 14% / 74% | 16% / 34% |
| Text 3 | 注記、メタ情報 | 12% / 62% | 12% / 42% |
| Disabled | 無効な部品の文字・つまみ | 10% / 40% | 10% / 72% |
| On Accent | アクセント色の上の文字 | 45% / 14% | 45% / 14% |
| Accent Line | 細い線、小さなアクセント文字 | Primaryと同じ | 55% / 42% |

例：Lavenderのダークの`Background`は`hsl(268, 26%, 8%)`となる。

`Accent Line`は、選択中の枠、タブの下線、ナビゲーションの選択表示、スライダーの塗り、小さな見出し文字に使う。ライトでは淡いPrimaryが背景と区別しにくいため、濃い色調に切り替える。

### 3.4 状態

| Token | 意味 | ダーク | ライト | 形（9.1） |
|---|---|---|---|---|
| Success | 成功、接続済み、良好 | `#52d6bd` | `#0e7d68` | ✓ |
| Warning | 注意、不安定 | `#ffc864` | `#8f5c00` | △（中に !） |
| Error | 失敗、見つからない | `#ff6f8e` | `#c41f4b` | × |
| Live | 配信中 | `#ff4f84` | `#b80f4a` | ●（塗りつぶし） |
| （なし） | 停止中、未接続 | Text 2 | Text 2 | ○（輪郭） |

- Successは、Errorとの区別がつきやすいよう、緑ではなく青緑寄りとする。
- 状態は、色だけでなく必ず形と文字を一緒に表示する（9.1）。

### 3.5 派生色

| Token | 定義 | 用途 |
|---|---|---|
| Glow | Primaryの不透明度35% | Primary Buttonやトグルの光彩 |
| Tint | SurfaceにPrimaryを14%混ぜた色 | ナビゲーションの選択背景 |
| 状態の淡い背景 | 状態色の不透明度14%（Liveは18%） | 状態表示（Chip）の背景 |

## 4. 文字

### 4.1 Font

| 用途 | Font | License |
|---|---|---|
| UI全般 | Noto Sans JP | SIL Open Font License 1.1 |
| 数値、ログ、識別子 | Noto Sans Mono | SIL Open Font License 1.1 |

- UI要素へFontを個別に指定しない。Typography Styleを通して使う（方式設計14.8）。
- 将来の言語追加に備え、Fallback Fontを設定できる構成とする（方式設計14.9）。

### 4.2 Typography Style

| Style | サイズ / 太さ | 行間 | 用途 |
|---|---|---|---|
| Heading | 22px / 700 | 1.3 | 画面の見出し |
| Subhead | 16px / 700 | 1.4 | セクション、設定項目名 |
| Body | 14px / 400 | 1.6 | 本文、ラベル |
| Caption | 12px / 400 | 1.5 | 補足、注記 |
| Button | 13px / 700 | 1.0 | ボタン |
| Numeric | 20px / 600、Mono | 1.2 | 数値の表示（等幅数字） |
| Monospace | 12px / 400、Mono | 1.5 | ログ、識別子 |

- 12pxより小さい文字は使わない。
- 列に並ぶ数値は等幅数字にする。

## 5. 余白

| Token | 値 | 主な用途 |
|---|---|---|
| XS | 4px | アイコンと文字の間 |
| S | 8px | 同じグループ内の部品の間 |
| M | 16px | カードの内側、カード同士の間 |
| L | 24px | 画面の内側、セクションの間 |
| XL | 40px | 大きなまとまりの間 |

余白はこの5段階からのみ選ぶ。

## 6. 形

| Token | 値 | 用途 |
|---|---|---|
| Radius S | 8px | 入力欄、小さな部品 |
| Radius M | 14px | カード、ナビゲーション項目、お知らせ |
| Radius L | 22px | 画面、ダイアログ |
| Radius Pill | 999px | ボタン、トグル、状態表示 |
| Border | 1px | 通常の枠線 |
| Border（エラー） | 2px | エラー状態の入力欄 |

ボタンとトグルを丸いピル形にすることが、見た目の印象の中心である。

---

## 7. 動き

- 状態の切り替え（ホバー、トグル）は0.12〜0.15秒程度の短い変化とする。
- 常に動く表現は、配信中を示す表示の点滅など、意味のあるものに限る。
- OSの「視覚効果を減らす」設定が有効な場合は、点滅や移動を止める。

## 8. Theme

利用者が選べる見た目の設定は次の3つとする。いずれもUI固有設定として保存する（方式設計14.38）。

| 設定 | 選択肢 | 既定 |
|---|---|---|
| パレット | Lavender、Sakura、Mint、Sky、Peach、Lemon | Lavender |
| 背景 | ダーク、ライト | ダーク |
| UIの拡大縮小 | 実装時に段階を決める | 100% |

## 9. だれにでも使いやすく

### 9.1 状態は色だけで伝えない

- 状態には3.4の形のアイコンと文字を必ず付ける。
- 色の見え方が人によって違っても区別できることを、見本ページの「色の見え方」切り替え（赤緑、青黄、白黒）で確認する。この切り替えは開発時の確認用であり、Applicationの画面には含めない。

### 9.2 読みやすさ

- 本文と背景のコントラストは4.5:1以上、大きな文字、アイコン、部品の境界は3:1以上とする。
- アクセント色の上の文字は`On Accent`とする。

### 9.3 操作しやすさ

- 押せる部品は24px以上の大きさとする。
- すべての操作をキーボードで行えるようにし、選択中の部品には必ず枠を表示する。
- 説明（ツールチップ）は、マウスのホバーだけでなくキーボードで選択したときにも表示する。

### 9.4 設定への追従

- UIの拡大縮小、パレット、ダーク／ライト、動きを減らす設定に追従する。
- 拡大しても文字が切れないよう、幅は固定せず中身に合わせる（方式設計14.7）。

## 10. Unityでの実装方針

詳細はUI基盤の詳細設計で定める。本書の範囲では次を前提とする。

- TokenはUSSのCustom Property（`--color-primary`等）として定義し、各ComponentのUSSは`var()`で参照する。
- USSは`color-mix()`やHSLの計算に対応しない。そのため、ニュートラルと派生色はパレット・背景の組み合わせごとに計算済みの値として用意する。生成方法は詳細設計で決める。
- Fontは、Noto Sans JPとNoto Sans MonoのFont AssetをTheme Style Sheetから指定する。

---

## 11. 変更手順

1. 本書と`docs/en/ui/design-system.md`を更新する。
2. `docs/assets/ui/styleboard.html`を同じ内容に更新する。
3. Unity側のTokenを更新する（実装後）。
4. ダーク、ライト、日本語、英語、色の見え方の各表示で確認する。
