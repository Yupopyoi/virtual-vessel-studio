# 共通Component

## 1. 目的

本書は、各画面が組み合わせて使う共通Componentの見た目と振る舞いを定める（方式設計14.5、14.34）。

値（色、余白、角丸、文字）はすべて`design-system.md`のTokenを使う。見た目の基準は`docs/assets/ui/styleboard.html`で確認できる。

各Componentについて、次の状態を定める。

- 通常
- ホバー
- 選択中（キーボードフォーカス）
- 押下
- 無効
- エラー（入力系のみ）

---

## 2. 共通の振る舞い

| 項目 | 内容 |
|---|---|
| フォーカス | キーボードで選択した部品には、2pxの`Accent Line`の枠を2px外側に表示する |
| 無効 | 背景`Surface 2`、文字`Disabled`、影なし。押せない理由をツールチップで示す |
| ツールチップ | 説明が必要な部品には付ける（3.12） |
| 文字 | すべてLocalization Keyから取得する（`ui-guidelines.md`） |
| 大きさ | 押せる部品は24px以上 |

---

## 3. Component

### 3.1 Button

| 種類 | 見た目 | 用途 |
|---|---|---|
| Primary | 背景Primary、文字On Accent、Glowの影 | 画面で最も重要な操作（1画面に1つを目安） |
| Secondary | 背景Surface 3、文字Text、1pxの枠 | それ以外の操作 |
| Danger | 背景Liveの淡色、文字Live、Liveの枠 | 配信終了など、取り消しにくい操作 |

- 形はRadius Control（角丸四角形）、文字はButton Style、内側の余白は上下8px・左右18px。
- 押下時は1px下へ移動する。
- Dangerは確認ダイアログ（3.11）を経てから実行する。

### 3.2 Icon Button

- 38pxの円形。背景Surface 3、1pxの枠。
- ミュートのように状態を持つものは、オンのとき背景Secondary、アイコンOn Accentとする。
- アイコンだけでは意味が伝わりにくいため、必ずツールチップを付ける。

### 3.3 Toggle

- 44×26px、Radius Round（高さの半分の13px）。つまみは20pxの円。
- オフ：背景Surface 3、つまみText 2。オン：背景Primary、つまみOn Accent、Glow。
- オンとオフは、色だけでなくつまみの位置でも区別できる。
- 名前の文字（ラベル）と一緒に配置する。

### 3.4 Slider

- 高さ6pxのトラック。値までをPrimary、残りをSurface 3で塗る。
- つまみは18pxの円（中Knob、縁Primary）。Knobはダークでは明るい色、ライトでは白に近い色で、ライトでも重く見えないようにする。
- 現在値を数値（Numericまたは等幅数字）で近くに表示する。単位も付ける（例：`−12 dB`、`+4`）。

### 3.5 Level Meter

- 音量などを示す24個の区切られたバー。
- 通常域はSuccess、上位25%はWarning、最上部（24個のうち上の2個）はError（赤）とする。音が割れる手前であることが分かるようにするためである。
- 塗りには鮮やかな塗り色（Success Fill、Warning Fill、Error Fill）を使い、ライトでも重く・地味に見えないようにする。
- 色に加えて、点灯している本数で量が分かる。

### 3.6 Dropdown

- 背景Background、1pxの枠、Radius S。右端に下向きの矢印。
- 選択肢の文字が長い場合は省略せず折り返すか、幅を広げる。

### 3.7 Text Field / Numeric Field

- 背景Background、1pxの枠、Radius S、上にラベル（Caption相当、Text 2）。
- 入力の例（プレースホルダー）はText 3で薄く表示し、入力された値ではなく例であることが分かるようにする。
- フォーカス時：枠Accent Line、外側にGlowの3px。Unityでは外側の光を描けないため、枠のAccent Lineだけで示す（UI基盤詳細設計6.7）。
- Numeric Fieldは右寄せの等幅数字とし、右側に単位の欄を付ける（例：`Hz`）。
- エラー時：枠を2pxのError、下に△アイコンとエラー文を表示する。エラー文は何が問題で、どうすればよいかを書く。

### 3.8 Tab

- 下線型。選択中は文字Text、2pxの下線Accent Line。それ以外は文字Text 2。
- 幅が足りない場合は横にスクロールする。

### 3.9 Setting Row

- 左に設定名（Body、太さ500。Mediumのないフォントでは通常の太さ）と説明（Caption、Text 3）、右に操作部品（最大260px）。
- 行の間は1pxの区切り線。
- 狭い画面では、操作部品を説明の下へ回す。

### 3.10 Card

- 背景Surface 2、1pxの枠、Radius M、内側の余白M。
- 上部にタイトル（13px、太さ700、Text）。右端に状態表示（3.13）を置ける。
- 同じ並びのCardは、内側の余白と配置をそろえる。
- 上端の線、タイトルの縦バー、タイトル部分のWashを付ける。並んだCardは1枚おきにSecondaryに替える（`design-system.md` 3.6）。

### 3.11 Dialog

- 背景Surface、1pxの枠、Radius L、内側の余白L、大きな影。最大幅420px。
  - Unityの実装では、影の代わりに画面全体を暗くする幕を使う（UI基盤詳細設計6.4）。
- タイトル（17px、太さ700）、本文（Text 2）、右下にボタン。
- 取り消しにくい操作の確認では、実行ボタンをDanger、もう一方をSecondaryの「キャンセル」とする。
- 本文には、実行すると何が起きるかを書く。

### 3.12 Tooltip

- 部品にマウスを約0.5秒止めると表示し、離れると消す。キーボードで選択したときにも表示する。時間と位置の数値は既定値であり、変更しうる（UI基盤詳細設計7.6）。
- 背景Surface 3、Primary寄りの1pxの枠、Radius S、Caption相当の文字。最大幅260px。
- 部品の上に表示し、上に余白がなければ下に表示する。画面の端からはみ出さない。
- 内容は「その操作で何が起きるか」を1文で書く。ショートカットキーがあれば右に添える。
- 無効な部品では、押せない理由と、押せるようになる条件を書く。
- 操作の中身を説明文に書き直すだけの内容（「ボタンです」等）は書かない。

### 3.13 Status Indicator（Chip）

- Radius Sの角丸四角形。アイコン、文字、必要なら数値（等幅）を並べる。
- 状態ごとの色と形は`design-system.md`の3.4に従う。
- 文字は太字とし、鮮やかな状態色で、LEDが点灯しているようにはっきり見せる。背景は状態の面（不透明）、枠は状態の枠を使う。
- 配信中（Live）のみ、アイコンをゆっくり点滅させる。動きを減らす設定では点滅しない。

### 3.14 Notification

- 背景Surface 2、1pxの枠、Radius M。左に状態のアイコン、右に見出し（太字）と本文。
- エラーは枠と背景にErrorを薄く混ぜる。
- 本文には、次に何をすればよいかを書く（例：「USBの接続を確認してから、もう一度お試しください。」）。
- 既定では右下に表示し、InfoとSuccessは約5秒、Warningは8秒で消える。Errorは閉じるまで残す。同時に3つまで表示する。位置と時間は既定値であり、変更しうる（UI基盤詳細設計7.8）。
- 表示しきれない通知は捨てずに待たせ、Errorを優先して順に表示する。待っている件数を、スタックの隅側の端に「ほかに N 件の通知」と表示する。見落とさないよう、通知とは違う見た目にする（＋のアイコン、太字のCaption、文字Text、背景Tint、Accent Lineの枠、Radius S）。

### 3.15 Progress Bar

- 高さ8px、Radius Round。PrimaryからSecondaryへのグラデーションで進捗を塗る。
- 上に何の進捗かと現在値を表示する（例：「RVC学習 · エポック 120 / 300」）。

### 3.16 Navigation Item

- 左側の縦並びメニュー。アイコンと文字。
- 選択中：背景Tint、文字Text、左端に3pxのAccent Line。
- 各項目にツールチップでその画面の役割を示す。
- TabとEnterで操作できる。項目の間は上下キーでも移れる。

### 3.17 Preview

- 配信映像のプレビュー。16:9を保ち、Radius M。
- 右上にフレームレートを状態表示（3.13）で示す。設定したフレームレートを保てていればSuccess、下回ればWarningとし、Tooltipで意味を説明する。
- 左下に「配信プレビュー · 1920×1080 · 6,000 kbps」のように解像度とビットレートを表示する。どんな映像の上でも読めるよう、背景Surface・1pxの枠の札に載せる。映像を符号化していないときはビットレートを出さない。
- 配信映像がまだないときは、中央に「配信映像はまだありません」と表示し、数値は出さない。
- 右下に全画面表示のIcon Buttonを置く。全画面中は映像だけを画面いっぱいに表示し、`Esc`、同じボタン、`F`キーで戻る。入るときも同じボタンか`F`キーとし、入り方と戻り方をそろえる。全画面に入った直後に「Esc か F で元に戻ります」と少しの間表示する。
- `Esc`は、映像を選択している間はまず選択を外し（配置編集、UI基盤詳細設計9.8）、何も選択していないときに全画面を終える。
- 全画面表示はプレビューの表示方法であり、配信出力（Stream Render Target）には影響しない（方式設計14.23）。
- 映像を選択している間は、左上にモード切り替え（3.18）を表示する。

### 3.18 Segmented（切り替えボタン）

- 2〜4個の選択肢から1つを選ぶ。背景、配置編集のモード等に使う。言語（文字列表を足すと増える）やUIの大きさ（6段階）は、Dropdownを使う。
- 外枠はRadius Control、各項目はRadius S相当（7px）。選択中は背景Primary、文字On Accent。
- 選択肢が5個以上、または文字が長い場合はDropdownを使う。

### 3.19 Media Frame（配置編集の枠）

配信画面上の映像（ゲーム画面、サブモニター等）の配置を編集する枠。操作の詳細はUI基盤詳細設計の9章で定める。

- 選択した枠は、Primaryの2pxの外枠と、角と辺の8つのハンドル（12pxの円）で示す。
- 配置編集には「配置」と「切り抜き」の2つのモードがある。現在のモードは、プレビュー左上の「モード [配置｜切り抜き]」で常に表示し、そこで切り替えられる。
- 切り抜きモードでは、外枠とハンドルをSecondaryにし、ハンドルを辺に沿った棒の形にする。映像全体を薄く表示し、どこまで戻せるかを示す。
- ハンドルにカーソルを合わせると、カーソルを ↔ ↕ ⤡ ⤢ に変える。枠の内側では移動の形、ロック中の枠では禁止の形にする。
- 操作中は、位置と大きさ（または拡大率）を枠の上に小さく表示する。
- ロック中の枠には「ロック中」の表示を付け、ハンドルを出さない。

### 3.20 Layer List（重なり順の一覧）

- 配信画面上の映像を、手前から順に縦に並べる。上が手前。
- 一覧の上に「上が手前」と小さく示す。
- 各行に、つかめることを示す「≡」、映像の小さな見本（サムネイル、40×23px、Radius 4px）、名前、状態（ロック中、非表示）を表示する。見本はプレビュー上の映像と行を結び付けやすくするためのもので、映像を受け取れない場合は無地（Surface 3）とする。
- 行をクリックすると選択し、上下にドラッグすると重なり順を変える。ドラッグ中は、落ちる位置にAccent Lineの線を表示する。
- 並べ替えは元に戻す（`Ctrl+Z`）の対象とする。
- キーボードでは、上下キーで選択を移し、`Ctrl`+上下キーで選択中の映像を1つ前（後ろ）へ動かす。プレビューの`]`・`[`と同じ動きとする。
- 選択中の行は背景Tint、左端に3pxのAccent Line（Navigation Itemと同じ）。非表示の行は名前と見本を薄くし、選べない。ロック中の映像は並べ替えられない。

### 3.21 Key Hint（キー表示）

- ショートカットや操作を示す小さな枠。背景Background、1pxの枠、Radius 5px、Monospace 11px。
- 枠は文字の高さに合わせ、並んでいる文字と上下中央をそろえる。行の高さいっぱいに伸ばさない。

### 3.22 Scroll Bar（スクロールバー）

- 矢印のボタンは置かない。幅12pxの中に、幅8px・角丸4pxのつまみを置く。
- つまみはPrimary（不透明度55%）、マウスを乗せると90%にする。溝はSurface 2の角丸とする。
- 画面の色に合わせて目立ちすぎないようにしつつ、パレットの色でかわいらしさを出す。

### 3.23 Popup Menu（右クリックメニュー）

- 指した位置に開くメニュー。背景Surface、1pxの枠、Radius M、内側の余白6px、最小幅250px。
- 各行に、オンかどうかを示すチェック（Accent Line）、項目名、ショートカット（Key Hint）を並べる。行の高さは32px以上。
- マウスを乗せた行とキーボードで選んでいる行は、背景をTintにする。使えない項目は文字をDisabledにし、選べないようにする。
- 区切りは1pxのBorderの線とする。
- 各項目にTooltipで、その操作で何が起きるかを示す。
- 開くとキーボードのFocusを受け取り、上下キーで移動、Enterで実行、Escで閉じる。項目を実行するか、外側を押すと閉じる。閉じたら、開く前の場所へFocusを戻す。
- 画面の端では、はみ出さないように左や上に向けて開く。

### 3.24 Table（表）

- 列ごとに、幅、寄せ（左・右）、文字の種類を決める。見出しとすべての行が同じ列の定義を使うため、列は必ずそろう。
- 文字は左寄せ、数値は等幅（Monospace）で右寄せにし、桁をそろえる。
- 各セルの左右に余白S（8px）を置く。そのため、隣の列との間は常に16px空く。
- 見出しはCaption、Text 3。行の高さは36px以上とし、行の間に1pxのBorderの線を引く。
- 残りの幅を使う列（名前など）を置ける。収まらない文字は末尾を「…」で省略する。
- 表示する幅が列の幅の合計より狭いときは、表の中だけを横にスクロールする。表の外へははみ出さない。縦のホイールは、これまでどおり画面全体をスクロールする。
- 表示を更新するときは、行を作り直さずに文字だけを変える。
