# 共通Component

## 1. 目的

本書は、各画面が組み合わせて使う共通Componentの見た目と振る舞いを定める（方式設計14.5、14.34）。

値（色、余白、角丸、文字）はすべて`design-system.md`のTokenを使う。見た目の基準は`docs/assets/ui/styleboard.html`で確認できる。

各Componentについて、次の状態を定める。

- 通常
- ホバー
- 選択中（キーボードフォーカス）
- 押下
- 無効
- エラー（入力系のみ）

---

## 2. 共通の振る舞い

| 項目 | 内容 |
|---|---|
| フォーカス | キーボードで選択した部品には、2pxの`Accent Line`の枠を2px外側に表示する |
| 無効 | 背景`Surface 2`、文字`Disabled`、影なし。押せない理由をツールチップで示す |
| ツールチップ | 説明が必要な部品には付ける（3.12） |
| 文字 | すべてLocalization Keyから取得する（`ui-guidelines.md`） |
| 大きさ | 押せる部品は24px以上 |

---

## 3. Component

### 3.1 Button

| 種類 | 見た目 | 用途 |
|---|---|---|
| Primary | 背景Primary、文字On Accent、Glowの影 | 画面で最も重要な操作（1画面に1つを目安） |
| Secondary | 背景Surface 3、文字Text、1pxの枠 | それ以外の操作 |
| Danger | 背景Liveの淡色、文字Live、Liveの枠 | 配信終了など、取り消しにくい操作 |

- 形はRadius Control（角丸四角形）、文字はButton Style、内側の余白は上下8px・左右18px。
- 押下時は1px下へ移動する。
- Dangerは確認ダイアログ（3.11）を経てから実行する。

### 3.2 Icon Button

- 38pxの円形。背景Surface 3、1pxの枠。
- ミュートのように状態を持つものは、オンのとき背景Secondary、アイコンOn Accentとする。
- アイコンだけでは意味が伝わりにくいため、必ずツールチップを付ける。

### 3.3 Toggle

- 44×26px、Radius Round（高さの半分の13px）。つまみは20pxの円。
- オフ：背景Surface 3、つまみText 2。オン：背景Primary、つまみOn Accent、Glow。
- オンとオフは、色だけでなくつまみの位置でも区別できる。
- 名前の文字（ラベル）と一緒に配置する。

### 3.4 Slider

- 高さ6pxのトラック。値までを`Accent Line`、残りをSurface 3で塗る。
- つまみは18pxの円（中Text、縁Accent Line）。
- 現在値を数値（Numericまたは等幅数字）で近くに表示する。単位も付ける（例：`−12 dB`、`+4`）。

### 3.5 Level Meter

- 音量などを示す24個の区切られたバー。
- 通常域はSuccess、上限付近（上位25%）はWarningとする。
- 色に加えて、点灯している本数で量が分かる。

### 3.6 Dropdown

- 背景Background、1pxの枠、Radius S。右端に下向きの矢印。
- 選択肢の文字が長い場合は省略せず折り返すか、幅を広げる。

### 3.7 Text Field / Numeric Field

- 背景Background、1pxの枠、Radius S、上にラベル（Caption相当、Text 2）。
- フォーカス時：枠Accent Line、外側にGlowの3px。
- Numeric Fieldは右寄せの等幅数字とし、右側に単位の欄を付ける（例：`Hz`）。
- エラー時：枠を2pxのError、下に△アイコンとエラー文を表示する。エラー文は何が問題で、どうすればよいかを書く。

### 3.8 Tab

- 下線型。選択中は文字Text、2pxの下線Accent Line。それ以外は文字Text 2。
- 幅が足りない場合は横にスクロールする。

### 3.9 Setting Row

- 左に設定名（Body、太さ500）と説明（Caption、Text 3）、右に操作部品（最大260px）。
- 行の間は1pxの区切り線。
- 狭い画面では、操作部品を説明の下へ回す。

### 3.10 Card

- 背景Surface 2、1pxの枠、Radius M、内側の余白M。
- 上部にタイトル（13px、太さ700、Text 2）。右端に状態表示（3.13）を置ける。
- 同じ並びのCardは、内側の余白と配置をそろえる。

### 3.11 Dialog

- 背景Surface、1pxの枠、Radius L、内側の余白L、大きな影。最大幅420px。
- タイトル（17px、太さ700）、本文（Text 2）、右下にボタン。
- 取り消しにくい操作の確認では、実行ボタンをDanger、もう一方をSecondaryの「キャンセル」とする。
- 本文には、実行すると何が起きるかを書く。

### 3.12 Tooltip

- 部品にマウスを約0.5秒止めると表示し、離れると消す。キーボードで選択したときにも表示する。
- 背景Surface 3、Primary寄りの1pxの枠、Radius S、Caption相当の文字。最大幅260px。
- 部品の上に表示し、上に余白がなければ下に表示する。画面の端からはみ出さない。
- 内容は「その操作で何が起きるか」を1文で書く。ショートカットキーがあれば右に添える。
- 無効な部品では、押せない理由と、押せるようになる条件を書く。
- 操作の中身を説明文に書き直すだけの内容（「ボタンです」等）は書かない。

### 3.13 Status Indicator（Chip）

- Radius Sの角丸四角形。アイコン、文字、必要なら数値（等幅）を並べる。
- 状態ごとの色と形は`design-system.md`の3.4に従う。
- 配信中（Live）のみ、アイコンをゆっくり点滅させる。動きを減らす設定では点滅しない。

### 3.14 Notification

- 背景Surface 2、1pxの枠、Radius M。左に状態のアイコン、右に見出し（太字）と本文。
- エラーは枠と背景にErrorを薄く混ぜる。
- 本文には、次に何をすればよいかを書く（例：「USBの接続を確認してから、もう一度お試しください。」）。

### 3.15 Progress Bar

- 高さ8px、Radius Round。PrimaryからSecondaryへのグラデーションで進捗を塗る。
- 上に何の進捗かと現在値を表示する（例：「RVC学習 · エポック 120 / 300」）。

### 3.16 Navigation Item

- 左側の縦並びメニュー。アイコンと文字。
- 選択中：背景Tint、文字Text、左端に3pxのAccent Line。
- 各項目にツールチップでその画面の役割を示す。

### 3.17 Preview

- 配信映像のプレビュー。16:9を保ち、Radius M。
- 右上にフレームレート、左下に解像度とビットレートを表示する。
- 右下に全画面表示のIcon Buttonを置く。全画面中は映像だけを画面いっぱいに表示し、`Esc`、同じボタン、`F`キーで戻る。
- 全画面表示はプレビューの表示方法であり、配信出力（Stream Render Target）には影響しない（方式設計14.23）。
- 映像を選択している間は、左上にモード切り替え（3.18）を表示する。

### 3.18 Segmented（切り替えボタン）

- 2〜4個の選択肢から1つを選ぶ。言語、背景、UIの大きさ、配置編集のモード等に使う。
- 外枠はRadius Control、各項目はRadius S相当（7px）。選択中は背景Primary、文字On Accent。
- 選択肢が5個以上、または文字が長い場合はDropdownを使う。

### 3.19 Media Frame（配置編集の枠）

配信画面上の映像（ゲーム画面、サブモニター等）の配置を編集する枠。操作の詳細はUI基盤詳細設計の9章で定める。

- 選択した枠は、Primaryの2pxの外枠と、角と辺の8つのハンドル（12pxの円）で示す。
- 配置編集には「配置」と「切り抜き」の2つのモードがある。現在のモードは、プレビュー左上の「モード [配置｜切り抜き]」で常に表示し、そこで切り替えられる。
- 切り抜きモードでは、外枠とハンドルをSecondaryにし、ハンドルを辺に沿った棒の形にする。映像全体を薄く表示し、どこまで戻せるかを示す。
- ハンドルにカーソルを合わせると、カーソルを ↔ ↕ ⤡ ⤢ に変える。枠の内側では移動の形、ロック中の枠では禁止の形にする。
- 操作中は、位置と大きさ（または拡大率）を枠の上に小さく表示する。
- ロック中の枠には「ロック中」の表示を付け、ハンドルを出さない。

### 3.20 Layer List（重なり順の一覧）

- 配信画面上の映像を、手前から順に縦に並べる。上が手前。
- 各行に、つかめることを示す「≡」、色の見本、名前、状態（ロック中、非表示）を表示する。
- 行をクリックすると選択し、上下にドラッグすると重なり順を変える。ドラッグ中は、落ちる位置にAccent Lineの線を表示する。
- 並べ替えは元に戻す（`Ctrl+Z`）の対象とする。

### 3.21 Key Hint（キー表示）

- ショートカットや操作を示す小さな枠。背景Background、1pxの枠、Radius 5px、Monospace 11px。
- 枠は文字の高さに合わせ、並んでいる文字と上下中央をそろえる。行の高さいっぱいに伸ばさない。

## 4. Componentの追加

1. 既存のComponentで足りないことを確認する。
2. 本書と`docs/en/ui/components.md`に仕様を追加する。
3. `docs/assets/ui/styleboard.html`に見本を追加する。
4. ダーク、ライト、日本語、英語、色の見え方の各表示で確認する。
