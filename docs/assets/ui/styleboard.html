成功は ✓、注意は △、失敗は ×、配信中は ●、停止中は ○。形と文字を必ず色と一緒に出すので、色の見え方が人によって違っても区別できます。

読みやすさ

本文と背景のコントラストは 4.5:1 以上、大きな文字やアイコンは 3:1 以上。アクセント色の上の文字は濃い色にします。文字は 12px 未満にしません。

操作しやすさ

押せる部品は 24px 以上。キーボードだけで全操作でき、選択中の部品には必ず枠を出します。説明はホバーだけでなくキーボードで選んだときにも出します。

設定で変えられること

UI の拡大縮小、パレット、ダーク／ライト、動きを減らす設定に対応します。拡大しても文字が切れないよう、幅は固定せず中身に合わせます。
