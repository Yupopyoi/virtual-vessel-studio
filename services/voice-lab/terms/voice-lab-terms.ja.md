# Voice Lab 利用規約

本規約は、Virtual Vessel Studio（以下「本ソフトウェア」といいます。）の機能である Voice Lab（以下「本機能」といいます。）の利用条件を定めるものです。利用者は、本規約に同意した上で、本機能を利用するものとします。

## 第1条（定義）

本規約において使用する用語の意味は、次の各号に定めるとおりとします。

1. 「利用者」とは、本機能を利用する者をいいます。
2. 「生成物」とは、本機能により作成された声のモデル、および当該モデルを用いて生成または変換された音声をいいます。
3. 「外部コンポーネント」とは、本機能を利用するために第9条に基づき取得されるソフトウェア、モデルその他のファイルをいいます。
4. 「開発者」とは、本ソフトウェアの開発者をいいます。

## 第2条（同意）

1. 利用者は、本規約の全文を確認し、これに同意した場合に限り、本機能を利用することができます。
2. 本機能の利用を開始するための操作をもって、利用者は本規約に同意したものとみなします。
3. 本規約に同意しない場合であっても、利用者は本機能以外の本ソフトウェアの機能を利用することができます。

## 第3条（禁止事項）

利用者は、本機能の利用にあたり、次の各号に該当する行為を行ってはなりません。

1. 他人になりすます行為
2. 詐欺その他の法令に違反する行為、またはそのおそれのある行為
3. 虚偽の情報を作成し、または拡散する行為
4. 本人の許諾を得ずに、他人の声を再現する行為
5. 実在の人物の声を模倣することを目的とした指示（プロンプトおよび追加の言葉を含みます。）を入力する行為
6. 第三者の肖像権、パブリシティ権、著作権その他の権利を侵害する行為
7. 前各号のほか、公序良俗に反する行為、または開発者が不適切と判断する行為

## 第4条（学習に使用する音声）

1. 利用者は、声のモデルの学習に、次の各号のいずれかに該当する音声のみを使用するものとします。
   1. 利用者自身の音声
   2. 利用者が使用する権利を有する音声（話者本人から許諾を得た音声を含みます。）
   3. 本機能により生成された音声
2. 利用者は、録音を取り込む場合、取り込む前に、当該録音が前項の条件を満たすことを確認するものとします。

## 第5条（AI 生成物の表示）

利用者は、生成物を公開する場合、当該音声が AI により生成または変換されたものであることを、視聴者が認識できる方法により表示するものとします。

## 第6条（利用者の責任）

1. 生成物の作成および利用、ならびにこれらによって生じた一切の結果については、利用者が責任を負うものとします。
2. 利用者は、生成物を配信または公開する前に、配信または公開する場の規約、ガイドラインその他の定めを確認し、これを遵守するものとします。
3. 利用者が本規約に違反したことにより第三者との間で紛争が生じた場合、利用者は自己の責任と費用においてこれを解決するものとします。

## 第7条（無保証）

1. 本機能および外部コンポーネントは、現状有姿で提供されます。開発者は、本機能および外部コンポーネントについて、特定の目的への適合性、正確性、有用性、継続的な提供、第三者の権利を侵害しないことその他一切の事項について、明示または黙示を問わず、何ら保証しません。
2. 外部コンポーネントの多くは、MIT License または Apache License 2.0 により提供されており、各ライセンスにおいても無保証とされています。

## 第8条（責任の制限）

開発者は、法令により認められる最大限の範囲において、本機能の利用または利用できないことにより利用者または第三者に生じた損害について、一切の責任を負わないものとします。

## 第9条（外部コンポーネントの取得）

1\. 本機能を利用可能にするにあたり、次の外部コンポーネントをインターネットから取得し、利用者が指定した場所に構築します。構築後の容量は約 13 GB であり、構築の途中においては、一時的に最大で約 30 GB の空き容量を必要とします。

| 名称 | 取得元 | ライセンス |
|---|---|---|
| uv（構築に使用する道具） | GitHub（astral-sh/uv） | MIT または Apache-2.0 |
| Python 3.12 | uv の配布物（python-build-standalone） | Python Software Foundation License |
| Python のパッケージ（PyTorch ほか） | PyPI、PyTorch の配布元 | 各パッケージのライセンス |
| RVC（Retrieval-based Voice Conversion WebUI） | GitHub | MIT |
| RVC の事前学習モデル、RMVPE、HuBERT | Hugging Face（lj1995/VoiceConversionWebUI） | MIT |
| VoxCPM2 | Hugging Face（openbmb/VoxCPM2） | Apache-2.0 |
| 声のひな形、配信用の共有モデル | Virtual Vessel Studio の GitHub Release | MIT |

2\. 本ソフトウェアは、各外部コンポーネントをその取得元からのみ取得します。取得したすべてのファイルは、取得後にハッシュ値により内容を検証し、一致しないものは使用しません。

3\. RVC の事前学習モデルは、次のデータを用いて学習されています。

> CSTR VCTK Corpus: English Multi-speaker Corpus for CSTR Voice Cloning Toolkit (version 0.92), Junichi Yamagishi, Christophe Veaux, Kirsten MacDonald, The Centre for Speech Technology Research (CSTR), University of Edinburgh. Creative Commons Attribution 4.0 International (CC BY 4.0).

4\. VoxCPM2 の提供者は、なりすまし、詐欺および偽情報への利用を禁止し、AI により生成された音声であることの表示を求めています。第3条および第5条は、これらの条件を含むものとします。

5\. 各外部コンポーネントのライセンスの全文は、本ソフトウェアの設定の「クレジットとライセンス」において確認することができます。利用者は、各外部コンポーネントのライセンスを遵守するものとします。

## 第10条（通信およびデータの取扱い）

1. 本機能は、外部コンポーネントの取得のためにインターネットに接続します。接続先は、前条に定める取得元に限られます。
2. 声の設計、学習用の音声の作成、学習および声の変換は、すべて利用者の PC 上で行われます。本機能は、録音、学習用の音声および生成物を外部に送信しません。
3. 構築した環境は、本機能の「作った声」から削除することができます。環境を削除した場合であっても、登録済みの声による配信には影響しません。

## 第11条（規約の変更）

1. 開発者は、必要と判断した場合、本規約を変更することができます。本規約には版を付すものとします。
2. 本規約を変更した場合、本ソフトウェアは、利用者が本機能により声を作成する前に、変更後の本規約への同意を求めます。
3. 前項の同意がない場合であっても、登録済みの声による配信は停止しません。

## 第12条（準拠法）

本規約は、日本法に準拠し、日本法に従って解釈されるものとします。
